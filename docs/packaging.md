# Packaging plan

How `wahwah` becomes importable by other projects, and how that extends to Swift and Python. The `wahwah` package exists in `packages/wahwah/` and the playground lives in `apps/playground/`; the Python and Swift crates below are planned. The ownership boundary with `wahwah-avatar` is in [Project goals](goals.md) and the [avatar split plan](avatar-split.md).

## Packages

- **`wahwah`** is one package with three entry points. `wahwah/performance` holds the types and helpers a host needs to play a performance (`FaceControls`, `FaceControlTrack`, `RenderedUtterance`, `Timeline`, `sampleFaceTrack`, `segmentAt`) and never loads WASM. `wahwah` adds the Rust/WASM voice engine and its presets. `wahwah/mumble` is the unstable Mumble generator and tokenizer. It has no dependencies. It is one package because no host would use the performance types without the engine, and because Swift and Python will each wrap the same Rust core.
- **The playground** is the app and stays private. It imports `wahwah` like any other consumer, which makes it the worked example. A test checks that the Tofu path does not reach past the package, and that the package imports only its own files.
- **Python and Swift** wrap the Rust core, not the TypeScript package. `crates/wahwah-python` (PyO3, built into wheels with maturin) feeds `packages/python`. `crates/wahwah-swift` (UniFFI or a C ABI, built into an XCFramework) feeds `packages/swift`.

## Distribution

| Target | How it ships |
| --- | --- |
| TypeScript, for now | GitHub release tarballs, tagged `v0.1.0`. CI builds the WASM, runs `npm pack` and attaches the file to a release. A consumer installs by URL, and the lockfile records its hash. |
| TypeScript, later | npm, with provenance from GitHub Actions ([#25](https://github.com/pomodorozhong/wahwah/issues/25)). Publishing waits until the split is confirmed finished. |
| Python | PyPI wheels, with a CI matrix for macOS, Linux and Windows. |
| Swift | A `binaryTarget` that points to an XCFramework zip attached to a release, with its checksum. |

Rejected:

- **A pinned git dependency.** npm cannot install a subfolder of a git repository, so the package layout cannot be installed that way.
- **GitHub Packages.** Installing needs a token even for public packages, and the scope must match the GitHub owner.

The tarball ships compiled `dist/`, type declarations, the built `.wasm` with its generated JavaScript, the licence and the third-party notices, so a consumer needs neither a TypeScript compile step nor a Rust toolchain. `rust-toolchain.toml` pins the toolchain that builds it.

During development, link a package with a `file:` path.

## Constraints

- **SwiftPM** reads `Package.swift` from the repository root and cannot point at a subfolder. Either keep `Package.swift` at the root, or put the Swift package in its own small repository.
- **Python wheels** are platform-specific, so the release workflow needs a build matrix.
- **The `wahwah` npm name** looked unclaimed when checked, but you still need an account and two-factor authentication before publishing. The engine includes code derived from klattsch and Babble Engine. Both upstreams are MIT, and the tarball carries their notices.

## Source of truth

Rust defines the format of the mouth controls, the track and the timeline. Shared JSON fixtures, such as a sample `FaceControlTrack`, are loaded by the tests of every language. The TypeScript `wahwah/performance` entry point is the JavaScript view of that format, so adding Swift and Python does not create a third definition.

## Order

1. Done: this plan, and the `wahwah` package with its release workflow ([#23](https://github.com/pomodorozhong/wahwah/issues/23)).
2. Done: the playground moved into `apps/playground/`, before the split, so the split steps use the final paths from the start.
3. Create `wahwah-avatar` and build its Tofu skeleton against the package.
4. Split steps 1, 2, 4 and 5, then step 3 (see the [avatar split plan](avatar-split.md)).
5. Publish to npm ([#25](https://github.com/pomodorozhong/wahwah/issues/25)).
6. Python and Swift, when a consumer needs them.
